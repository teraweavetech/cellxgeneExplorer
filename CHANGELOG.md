# Changelog

## 1.0.0
- Single-study explorer: CELLxGENE search and download, cellular, cell-specific and patient-level analysis of one gene,
  group selection, study folders, calculation guide, methods text, data report.
- Differential expression: NEBULA (gene+ vs gene- cells per cell type, pooled and within groups) and Fisher's exact
  tests for cell proportions.
- Optional descriptive report written by a local gpt-oss:20b model, generated only on request.
- Cross-study summary: inventory, study details with citations, study x cell type heatmaps, consistency,
  patient-level summaries, groups, and cell-type-specific reports.
- Interactive plots (hover, zoom) in notebooks and a browser app (`cxg-explorer app`).
